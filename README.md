# ESP32 Built-In Sensor Web Control System

A lightweight, local web-based control dashboard for the ESP32 using only **built-in hardware features**—the onboard LED and capacitive touch sensor—without requiring any external modules.

This project is designed to be beginner-friendly yet professional, showing how to turn an ESP32 into a fully interactive local Web Control System.

---

## 🔥 Features

- **Real-time responsive dashboard** served directly from the ESP32  
- **IST clock** synced using NTP  
- **Built-in LED control**  
  - ON / OFF  
  - PWM brightness adjustment (0–255)  
- **Capacitive touch sensor monitoring** (GPIO4)  
  - Live readings, auto-updated  
- **System information (IP, heap memory, chip ID)** revealed safely via `/system/info`  
- **Clean, mobile-friendly UI** (HTML / CSS only)  
- **No external sensors or hardware required**
